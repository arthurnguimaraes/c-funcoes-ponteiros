# Funções e Ponteiros em C

Exercícios de C sobre funções e ponteiros, feitos na disciplina de Estrutura de Dados I, com exercícios propostos pelo professor George Mendes Marra.

## Estrutura

- `funcoes/` — 10 exercícios sobre funções: passagem de parâmetros por valor e por referência, cálculo de área/perímetro e total de compra, validação de erros e manipulação de arrays dentro de funções.
- `ponteiros/` — 10 exercícios sobre ponteiros: declaração e uso, troca de variáveis (swap), percorrer e somar arrays, tamanho de strings, ponteiro para ponteiro e alocação dinâmica de memória.

## Como compilar e rodar

Cada arquivo é independente:

```bash
gcc funcoes/funcao1.c -o funcao1
./funcao1
```

(troque `funcao1.c` pelo arquivo desejado, em `funcoes/` ou `ponteiros/`)
